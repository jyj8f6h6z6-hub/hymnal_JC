詩歌數字轉盤｜v5

本版一起修改三件事：

1. 歌本改成「大封面橫向轉盤」
   - 中央選中的歌本最大
   - 左右仍會露出其他歌本，提示可以滑動
   - 詩歌本／補充本／新歌頌詠／兒童詩歌沿用 images 裡的正式封面
   - 紅本新詩、藍本新詩維持原本文字色塊

2. 數字轉盤方向反轉
   - 手指往下滑：數字變大
   - 手指往上滑：數字變小
   - 仍維持每格 70px、總高度 210px
   - 初始值仍為 0001
   - 搜尋結果與手機詩歌切換仍會同步數字轉盤

3. 首頁順序
   - 歌本
   - 數字轉盤
   - 搜尋
   - 詩歌內容

如何使用：
- 替換 index.html
- 替換 style.css
- 新增 enhancements.js
- 原本 app.js、hymns.js、images/、manifest.webmanifest 全部保留

特別說明：
這版沒有直接大改原本 app.js，而是用 enhancements.js 專門覆寫「歌本轉盤」與「數字方向」。
這樣比較容易回復，也比較不會影響原本搜尋、歌詞與手機詩歌橫向切換功能。
