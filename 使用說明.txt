補充本 Cs 正式斷行校正工具 v15

這版依你的要求修改：

1. 預檢不再因某一首歌詞版本不同而停止整本。
2. 文字完全或高度一致：
   → 依 hymnal.net Cs 正式版修正換行。
3. 歌詞文字版本不同：
   → 該首直接跳過。
   → 保留 hymns.js 原歌詞。
   → 報告標記「歌詞版本不同，未修改」。
4. 其他補充本歌曲繼續處理。
5. 最後報告會列出所有版本不同的歌號。

仍然保持：
- 只處理 book: 2
- code N 對應 https://www.hymnal.net/zh/hymn/ts/N
- 只修改 lyrics 的換行
- 不改歌詞文字
- 不改 code
- 不改 title
- 不改 favorite
- 不碰其他歌本
- 執行前自動備份 hymns.js

注意：
Cs3 因你目前 hymns.js 的歌詞文字和 hymnal.net Cs3 不同，
v15 會顯示「歌詞版本不同，跳過；保留原歌詞」，
但不會再阻止其他歌曲繼續處理。

完成後會產生：
linebreak_report_supplement_v15_日期時間.csv

使用：
1. 將 linebreak_tool.ps1 與 run_linebreak_tool.cmd 覆蓋到 D:\hymnal_JC
2. 雙擊 run_linebreak_tool.cmd
3. 讓它跑完整本
4. 完成後把 CSV 報告上傳給 ChatGPT 檢查
